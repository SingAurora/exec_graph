# ExAct 全局页面与行动模型

当前实现范围为 `frontend` 静态前端。图详情沿用既有设计，全局入口统一读取行动节点，停止使用旧的计划、完成、行动主题与相信/存疑流程。

登录后的应用背景右上角使用 Open Doodles 的 groovy 散步小人（来源：https://www.opendoodles.com/）。插画略向左倾斜并伸出屏幕边缘，采用随明暗主题变化的低对比灰绿色，固定在页面背景层，不占布局、不响应鼠标、不加入辅助阅读顺序。登录页沿用原有独立设计。

## 用户资料入口

各内容列表、用户搜索、参与者和节点详情中的用户头像或昵称先打开资料卡片，再通过卡片内头像或昵称进入可分享的用户主页。下文的“头像进入主页”均采用这一步预览。卡片复用主页背景、48px 圆形头像、昵称、性别与简介摘要，不公开账号邮箱；点击外部或按 Esc 收起。左下角已经展开的本人资料卡保持直接进入主页，继续显示当前账号邮箱。跳转主页后返回，恢复原列表的 tab 和阅读状态。

## 页面职责

个人主页首页的时间线在固定 420px 高的内容区内部滚动，热力图、时间线标题和日期筛选操作位于滚动区外。滚动到边缘不带动整页；无限加载以时间线区域为观察根。切换栏目及往返行动详情保留内部阅读位置，变更或清除日期筛选时回到区域顶部。内容区可通过键盘聚焦并滚动，不另加卡片外框。

时间线采用活动日志样式：左侧 24px Footprints 圆形标记与细连接线，右侧为行动标题，下方显示最多两行的行动正文摘要，超出省略，最后显示自适应日期时间。摘要去掉 Markdown 标记、图片及与标题重复的文档标题；无正文则省略摘要，点击标题或摘要进入行动文档。末条标记后不延长连接线，不另设日期分组标题或图片。

- 我的：直接展示本人的公开主页，取消“总览 / 主页”两层切换和最近内容分区。保留封面、头像、简介与表达/约定/行动/图统计，内容为“首页 / 表达 / 约定 / 行动 / 图 / 搜索”六个固定 tab。首页展示过去 365 个本地自然日的行动热力图，只统计本人发布的行动，不因表达或约定编辑重复增加次数；颜色随当天行动次数加深，悬浮显示日期与次数，点击日期筛选下方时间线，再次点击或清除筛选恢复全部日期。时间线按行动发布时间倒序，一次行动只占一条，每条显示行动标题、最多两行的行动摘要与自适应日期时间，不显示图片、表达或约定信息。点击标题或摘要进入行动文档，时间仅作元信息，悬浮显示完整日期时间。时间线及各内容列表无限加载，保留日期筛选、加载数量与阅读位置。本人图 tab 顶部保留发起行动图与管理行动图入口；行动图不单列为全局导航。
- 发现：表达 / 约定两个固定 tab，默认表达。用户从内容认识图，不提供独立的图 tab。两栏均采用左侧内容流与右侧 220px 窄栏，右栏“近期活跃的图”作为继续浏览的辅助入口，最多展示 3 个图的头像、名称、实际参与人数和最近行动时间，滚动时停留在导航下方。表达取路线终点的有效表达，按节点发布时间倒序；约定取明确满足的跨用户引用，按回应行动时间倒序。侧栏只展示已有行动的公开图，按最近行动时间排序，修改图资料不改变排名。发现页不单独展示或搜索行动列表；行动作为表达与约定的依据，在图详情和个人主页保留。
- 发现与关注列表：两处共用同一套内容流条目与所属图入口。作者与时间在上，表达正文为视觉主体，摘要最多 3 行，不另设表达标题；最近行动标题作为次要信息。约定保留“谁满足谁的约定”、约定摘要与回应行动。所属图入口移至底部，表达展示去重后的上下文行动总数（含当前行动及合入来源），隐藏节点编号、层级与技术来源；继承他人表达时保留作者归属。图片区沿用最多 3 张 144px 正方形缩略图和角落 +N 标记。正文进入节点或箭头，头像昵称打开资料卡片，卡片内头像昵称进入主页，图片独立预览。
- 主页搜索：导航末尾设置独立“搜索”tab，内部使用表达 / 约定 / 行动 / 图四个分类，普通内容栏目只浏览列表，不显示搜索框或筛选项。只搜索当前主页用户栏目已有内容；表达搜索有效正文、最近行动标题及相关作者，约定搜索约定内容、回应行动标题及双方作者，行动搜索标题、行动记录及作者，图搜索名称与简介。不检索图片地址、AI 对话或其他文档。各分类分别保留输入草稿、已提交条件、结果页码及阅读位置，点击搜索或按回车提交，支持重置；没有条件时不展示结果。结果每页 6 条，显示总数、关键词高亮及无结果提示，保留详情、资料卡和图片预览交互。搜索不影响普通栏目列表，切换或往返详情保留双方的阅读状态。
- 发现搜索：导航右侧提供当前栏目的搜索框，分别搜索表达正文与最近行动标题 / 约定及回应行动；也可按相关作者昵称搜索，保持原有时间顺序，不检索图片地址。搜索仅筛选当前内容流，不影响右侧图入口。两个栏目独立保留搜索词、已加载内容和滚动位置；修改关键词重置对应列表，切换栏目不重置。搜索时显示结果数，无结果可直接清除关键词。两栏保持无限滚动，往返详情或主页恢复阅读状态；没有更多内容时显示“没有更多了”。不增加热门、精华、推荐评分或常显说明段落。
- 右侧图搜索：在“近期活跃的图”标题下提供紧凑搜索框，按所有公开图的名称、简介搜索，包括尚无行动的新图。未输入或清空时恢复 3 个近期活跃图；输入后显示结果总数与最多 3 个匹配图，按最近行动时间排序，无行动则使用创建时间。搜索词独立保留，切换表达、约定或往返详情不重置。超过 3 个结果时显示“查看更多”，进入独立的图搜索结果页（每页 10 个）；关键词和页码进入地址，打开图后返回仍保留结果与位置。结果页侧栏保持“发现”选中，顶部提供“返回发现”，发现页不增加图 tab。
- 关注：表达 / 约定 / 图 / 用户四个 tab，默认表达。表达与约定复用发现的条目样式和无限滚动，保留关注范围内的内容筛选；图、用户 tab 是各自的关注对象列表，可按名称搜索、取消关注。关注图包含图内所有人的更新，关注用户包含该用户跨图的更新，两种来源取并集，不重复展示同一节点或箭头。约定动态包含关注图内的已满足跨用户引用，或关注用户作为满足者、实际约定提出者的回应；继承约定不能归给中间传递者。当陌生回应者仅因约定提出者被关注而进入列表时，底部保留“回应了你关注的某某”提示。图和用户目录按最近行动倒序排列，显示头像、名称、简介、最近行动时间与已关注按钮。各 tab、目录搜索草稿、已加载内容和滚动位置保留，条目交互与发现一致。
- 行动图（我的下级页面）：全部、我参与的、我发起的；支持名称/简介搜索、排序与分页。侧边栏保持“我的”选中，页面可返回我的。
- 用户主页：本人和他人使用相同的六栏目主页，默认首页；本人地址与“我的”共用同一份状态，他人保留关注按钮，不显示本人邮箱和图管理入口。表达、约定复用发现/关注的内容流条目，约定统计包含本人满足他人与他人满足本人，按实际约定提出者归属。已访问用户的日期筛选、列表、tab 状态保留，深链接仍可直接进入相应内容栏目。各栏目独立保留阅读位置：导航尚未吸顶时保持当前位置，已经吸顶时恢复目标栏目的阅读位置，但不回到导航上方；首次进入且导航已吸顶时从列表开头开始。切换前后在绘制阶段恢复位置，短列表至少保留一屏高度，避免高度收缩造成跳动。
- 设置：个人资料、AI 服务、账户安全、外观、测试账户的组件演示。保留各 tab 的草稿，保存资料给出轻提示。

## 数据口径

约定搜索支持双向参与者筛选。个人主页“搜索 → 约定”提供“往来对象”，选择后只显示主页用户与该对象之间的双方记录，可叠加关键词；全部对象取消对象限制。图内约定搜索使用“参与者一 / 参与者二”，只选一人显示其作为满足者或实际约定提出者的记录，选两人显示两人之间的双向记录，不能重复选择同一人。以约定实际提出者归属，不把继承节点作者算作提出者；继续只展示明确满足的跨用户引用，按回应行动时间倒序。主页普通内容列表保持无限加载，主页搜索与图内搜索保留提交、重置及分页；切换和返回保留筛选与阅读状态，点击记录仍定位到对应箭头。

- 行动是实际做过的事情，没有计划、目标、进行中或待完成状态。
- 表达列表取当前链路终点的有效表达。先在完整节点集合中判断终点，再按作者筛选，不能把某位作者已经被他人接续的旧节点误当成终点。
- 表达未修改时沿承接来源继承，显式空字符串停止继承；有效表达为空时不展示、不计数、不进入表达搜索结果。
- 参与人数按图内实际发布行动的不同作者计算，不使用旧的 `participantIds` 列表作为人数来源。
- 我参与的图仅包含本人实际发布过行动的图；我发起的图包括尚无节点的空图。个人相关图为这两类的并集。
- 发起图只创建公开空间，不自动生成节点。空图的第一次行动仍从图名片进入；已有节点的图需选择来源节点后接续。
- 用户关注入口保留在他人主页，不能关注自己；图关注入口在图名片底部最右侧。空图保留禁用按钮，悬浮或聚焦提示“发布第一次行动后才能关注此图”，发布首个节点后可用，提交时也核对图存在且有节点。创建、参与与关注互相独立，关注不改变编辑权限或参与数。取消关注显示可撤销的轻提示，不弹确认框；删除图同时清除该图的关注关系，撤销时按最新资源重新核对。关注状态沿用静态原型的会话内状态，不模拟服务端持久化。
- 权限和删除流程沿用既有规则，AI 服务商与密钥处理沿用当前实现。账户邮件与密码服务未接入时，不显示虚构的发送/修改成功。

## 阅读与返回

- 全局列表复用图内摘要样式：三行文本、至多三张正方形缩略图，更多图片显示角标。
- 正文点击通过带节点和文档类型的图链接进入探索，选中节点、切换行动/表达并高亮链路。
- 图片打开预览；用户头像昵称先打开资料卡片，卡片内头像昵称进入用户主页；时间、层级不承担跳转操作。图名称可进入相应行动图。
- 全局页与各内容 tab 保留筛选、已加载数据和滚动位置；从节点、用户主页返回列表时恢复位置。
- 接续行动、第一次行动、补充/修改表达与约定编辑自动保存本地草稿，使用当前浏览器的 IndexedDB，不上传或同步云端。草稿按账号、图、操作类型及目标节点隔离；行动和表达沿用同一段连续 AI 对话。保存未发送输入、对话、生成文档、继承/修改/清空选择、合入来源与约定核对结果，以及工作区 tab 和面板阅读位置。重新进入或刷新自动恢复；编辑地址保留图和节点标识，不包含草稿正文。顶部使用轻量保存状态，提供确认后放弃草稿；只有发布/保存成功才清理对应草稿，失败或离开继续保留。恢复时如已发布的引用背景发生变化，保留草稿内容，但需继续 AI 对话重新整理后才能提交。草稿不等于已发布内容，不自动发布节点；静态原型中的已发布数据仍沿用会话内状态。
- 图自己的 tab、画布、阅读区域与形成过程/接续行动的返回状态仍由原有图阅读工作区管理。

## 视觉约定

- 外观设置明确选择浅色或深色，与侧边栏的主题按钮同步，并在当前浏览器记忆。节点图背景参数与实时预览并排，四种背景分别保留参数；纯色隐藏纹理控件。图例开关同步更新预览和所有行动图，预览与实际画布复用同一图例。恢复默认只重置背景及全部纹理参数，不重置主题和图例。全部立即生效，具体说明放在问号帮助中。
- 沿用绿色强调色、灰绿底色与主题变量，选中 tab 使用底部强调线。
- 全局页只保留一处页面标题，避免重复的英文眉题和说明段落。
- 正文/表单使用 14px，内容标题 16px，页面标题 22px；元信息使用 12px。
- 全局表单高度 40px，操作复用主按钮、轻按钮、文字按钮与组件库 Select。
- 导航底部保留个人资料卡与内容快捷入口，以及主题和退出操作；“我的”与公开主页共用身份信息和封面展示。
- 空列表有明确的空状态；说明与限制尽量放入问号帮助。

## 旧原型兼容

尚未删除被其他旧演示组件引用的历史类型和文件。它们没有全局运行入口；旧主题路由回退到发现。删除图的既有兼容函数仍能清理历史记录，本次运行只传入行动数据。
