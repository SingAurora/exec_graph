# ExAct 全局页面与行动模型

当前实现范围为 `frontend-v2` 静态前端。图详情沿用既有设计，全局入口统一读取行动节点，停止使用旧的计划、完成、行动主题与相信/存疑流程。

## 页面职责

- 我的：包含“总览 / 主页”两个 tab。总览顶部用紧凑数据条展示行动、表达、约定和相关图的总数，数字 24px、标签 12px，点击进入对应完整栏目。下方左右两列：左侧先展示最近行动，最新一条保留标题、两行摘要与单张封面，另外两条使用较小标题、单行摘要及较小封面；再展示最近表达，直接突出三行有效正文，图名、节点编号与时间作为辅助信息，避免与行动重复显示相同标题。两类内容按栏目统一使用浅色底面，不给每条加外框或分隔线。右侧依次展示最近约定与最近的图，统一使用柔和底色。约定包含本人满足他人、他人满足本人的有效跨用户引用，继承约定按实际提出者归属，正文点击定位真实箭头，头像昵称进入主页，时间不跳转。图入口保留头像、名称、最近参与时间，不重复简介，发起按钮放在栏目标题右侧。行动、表达、约定、图各最多 3 条，不使用无限流；“查看全部”进入对应完整列表。文档图片独立预览，正文进入相应节点。最近的图按本人最近行动时间排序，无行动的自建图按创建时间排序。行动图不单列为全局导航。
- 发现：表达 / 约定 / 行动 / 图四个固定 tab，默认表达。前三栏采用左侧内容流与右侧 220px 窄栏，右栏“近期活跃的图”最多展示 3 个图的头像、名称、实际参与人数和最近行动时间。图 tab 使用完整宽度，不重复侧栏。表达取路线终点的有效表达，行动取所有已发布节点，均按节点发布时间倒序；约定取明确满足的跨用户引用，按回应行动时间倒序。图只展示已有行动的公开图，按最近行动时间排序，修改图资料不改变排名。每条内容顶部提供所属图入口，正文进入节点或箭头，头像昵称进入主页，图片独立预览。四栏保持无限滚动、已加载内容和独立滚动位置，往返详情或主页恢复阅读状态；没有更多内容时显示“没有更多了”。不增加热门、精华、推荐评分或常显说明段落。
- 关注：动态 / 图 / 用户三个 tab，默认动态。动态下分表达 / 约定 / 行动，复用现有摘要和无限滚动；图、用户 tab 是各自的关注对象列表，可按名称搜索、取消关注。关注图包含图内所有人的更新，关注用户包含该用户跨图的更新，两种来源取并集，不重复展示同一节点或箭头。约定动态包含关注图内的已满足跨用户引用，或关注用户作为满足者、实际约定提出者的回应；继承约定不能归给中间传递者。图和用户目录按最近行动倒序排列，显示头像、名称、简介、最近行动时间与已关注按钮。各级 tab、搜索草稿、已加载内容和滚动位置保留，正文仍进入对应节点或箭头，头像进入主页，图片独立预览。
- 行动图（我的下级页面）：全部、我参与的、我发起的；支持名称/简介搜索、排序与分页。侧边栏保持“我的”选中，页面可返回我的。
- 用户主页：公开身份、行动/表达/约定/图统计，以及表达、约定、行动、相关图四个 tab。约定统计与总览使用同一交流口径。本人从“我的 → 主页”进入，头像链接仍使用可分享的用户主页地址；访问本人地址时选中“我的”的主页 tab。访问其他用户时只展示对应公开主页，不展示“总览 / 主页”切换。所有入口复用同一份主页内容与列表状态。
- 设置：个人资料、AI 服务、账户安全、外观、测试账户的组件演示。保留各 tab 的草稿，保存资料给出轻提示。

## 数据口径

- 行动是实际做过的事情，没有计划、目标、进行中或待完成状态。
- 表达列表取当前链路终点的有效表达。先在完整节点集合中判断终点，再按作者筛选，不能把某位作者已经被他人接续的旧节点误当成终点。
- 表达未修改时沿承接来源继承，显式空字符串停止继承；有效表达为空时不展示、不计数、不进入表达搜索结果。
- 参与人数按图内实际发布行动的不同作者计算，不使用旧的 `participantIds` 列表作为人数来源。
- 我参与的图仅包含本人实际发布过行动的图；我发起的图包括尚无节点的空图。个人相关图为这两类的并集。
- 发起图只创建公开空间，不自动生成节点。空图的第一次行动仍从图名片进入；已有节点的图需选择来源节点后接续。
- 用户关注入口保留在他人主页，不能关注自己；图关注入口在图名片底部最右侧。空图保留禁用按钮，悬浮或聚焦提示“发布第一次行动后才能关注此图”，发布首个节点后可用，提交时也核对图存在且有节点。创建、参与与关注互相独立，关注不改变编辑权限或参与数。取消关注显示可撤销的轻提示，不弹确认框；删除图同时清除该图的关注关系，撤销时按最新资源重新核对。关注状态沿用静态原型的会话内状态，不模拟服务端持久化。
- 权限和删除流程沿用既有规则，AI 服务商与密钥处理沿用当前实现。账户邮件与密码服务未接入时，不显示虚构的发送/修改成功。

## 阅读与返回

- 全局列表复用图内摘要样式：三行文本、至多三张正方形缩略图，更多图片显示角标。
- 正文点击通过带节点和文档类型的图链接进入探索，选中节点、切换行动/表达并高亮链路。
- 图片打开预览，头像昵称进入用户主页；时间、层级不承担跳转操作。图名称可进入相应行动图。
- 全局页与各内容 tab 保留筛选、已加载数据和滚动位置；从节点、用户主页返回列表时恢复位置。
- 图自己的 tab、画布、阅读区域与形成过程/接续行动的返回状态仍由原有图阅读工作区管理。

## 视觉约定

- 沿用绿色强调色、灰绿底色与主题变量，选中 tab 使用底部强调线。
- 全局页只保留一处页面标题，避免重复的英文眉题和说明段落。
- 正文/表单使用 14px，内容标题 16px，页面标题 22px；元信息使用 12px。
- 全局表单高度 40px，操作复用主按钮、轻按钮、文字按钮与组件库 Select。
- 导航底部保留原有个人资料卡（头像、昵称、性别、邮箱、简介、活跃天数、发起图数、完成记录数），以及主题和退出操作；我的页面不重复展示大头像与个人简介。
- 空列表有明确的空状态；说明与限制尽量放入问号帮助。

## 旧原型兼容
