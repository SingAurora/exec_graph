# ExAct 全局页面与行动模型

当前实现范围为 `frontend-v2` 静态前端。图详情沿用既有设计，全局入口统一读取行动节点，停止使用旧的计划、完成、行动主题与相信/存疑流程。

## 页面职责

- 我的：包含“总览 / 主页”两个 tab。总览沿用旧版数据大数字、标签在下的层次，展示行动数、表达数、发起图数、参与他人图数。下方分为内容区和图入口侧栏：内容区分别展示最近 3 条有效表达、最近 3 次个人行动，使用标题、两行摘要、单张封面、图名及时间组成的有限预览，不使用内容分类双 tab 或无限流；“查看全部”进入主页 tab 的对应分类。图片点击独立预览，正文进入具体节点。侧栏展示最近 3 个相关图的头像、名称、简介与本人关系，保留全部行动图和发起图入口。三类最近内容均最多显示 3 条。最近的图按本人最近行动时间排序，无行动的自建图按创建时间排序。行动图不单列为全局导航。
- 发现：所有公开图中当前有效的表达与已发布行动。
- 关注：相同阅读方式，只筛选关注的作者；用户主页可关注或取消关注。
- 行动图（我的下级页面）：全部、我参与的、我发起的；支持名称/简介搜索、排序与分页。侧边栏保持“我的”选中，页面可返回我的。
- 用户主页：公开身份、行动/表达/图统计，以及表达、行动、相关图三个 tab。本人从“我的 → 主页”进入，头像链接仍使用可分享的用户主页地址；访问本人地址时选中“我的”的主页 tab。访问其他用户时只展示对应公开主页，不展示“总览 / 主页”切换。所有入口复用同一份主页内容与列表状态。
- 设置：个人资料、AI 服务、账户安全、外观、测试账户的组件演示。保留各 tab 的草稿，保存资料给出轻提示。

## 数据口径

- 行动是实际做过的事情，没有计划、目标、进行中或待完成状态。
- 表达列表取当前链路终点的有效表达。先在完整节点集合中判断终点，再按作者筛选，不能把某位作者已经被他人接续的旧节点误当成终点。
- 表达未修改时沿承接来源继承，显式空字符串停止继承；有效表达为空时不展示、不计数、不进入表达搜索结果。
- 参与人数按图内实际发布行动的不同作者计算，不使用旧的 `participantIds` 列表作为人数来源。
- 我参与的图仅包含本人实际发布过行动的图；我发起的图包括尚无节点的空图。个人相关图为这两类的并集。
- 发起图只创建公开空间，不自动生成节点。空图的第一次行动仍从图名片进入；已有节点的图需选择来源节点后接续。
- 权限和删除流程沿用既有规则，AI 服务商与密钥处理沿用当前实现。账户邮件与密码服务未接入时，不显示虚构的发送/修改成功。

## 阅读与返回

- 全局列表复用图内摘要样式：三行文本、至多三张正方形缩略图，更多图片显示角标。
- 正文点击通过带节点和文档类型的图链接进入探索，选中节点、切换行动/表达并高亮链路。
- 图片打开预览，头像昵称进入用户主页；时间、层级不承担跳转操作。图名称可进入相应行动图。
- 全局页与各内容 tab 保留筛选、已加载数据和滚动位置；从节点、用户主页返回列表时恢复位置。
- 图自己的 tab、画布、阅读区域与形成过程/接续行动的返回状态仍由原有图阅读工作区管理。

## 视觉约定

- 沿用绿色强调色、灰绿底色与主题变量，选中 tab 使用底部强调线。
- 全局页只保留一处页面标题，避免重复的英文眉题和说明段落。
- 正文/表单使用 14px，内容标题 16px，页面标题 22px；元信息使用 12px。
- 全局表单高度 40px，操作复用主按钮、轻按钮、文字按钮与组件库 Select。
- 导航底部保留原有个人资料卡（头像、昵称、性别、邮箱、简介、活跃天数、发起图数、完成记录数），以及主题和退出操作；我的页面不重复展示大头像与个人简介。
- 空列表有明确的空状态；说明与限制尽量放入问号帮助。

## 旧原型兼容

尚未删除被其他旧演示组件引用的历史类型和文件。它们没有全局运行入口；旧主题路由回退到发现。删除图的既有兼容函数仍能清理历史记录，本次运行只传入行动数据。
