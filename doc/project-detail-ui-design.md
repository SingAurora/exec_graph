# 行动图页面 UI 设计

本文记录行动图页面当前确定的展示逻辑。当前 frontend 为静态原型，真实发布与 AI 背景校验仍需后续接入。不符合来源约定仍可引用，只在连线上标记 ×，不设申请或审批流程。

## 1. 页面定位与导航

行动图用于公开记录持续发生的行动，以及这些行动如何连接成不同路线。发起者只是创建起点；所有人都可以接续，引用不符合来源约定时保留标记和原因。行动图不是任务清单，不要求预先制定计划或目标。

顶部区域命名为“图名片”，展示背景、头像、标题及参与数、表达数；表达、行动列表右侧的区域命名为“图资料”，展示图简介和统计数据。标题与简介描述这个公开空间，不限定后续每条路线必须表达同一观点。创建图只建立空间，不自动生成节点，也不自动进入行动编辑。没有节点时，“记录第一次行动”按钮统一放在图名片底部信息栏的最右侧，表达、行动、探索 tab 仅显示空状态，搜索 tab 保留但禁用。首次行动发布后，该按钮消失，搜索恢复可用。首次行动由用户单独发布，无上级引用，编号从 #1 开始、层级为 1，表达可填或留空；之后通过具体节点接续行动。修改图设置不回写节点的历史内容。

图资料不显示“图资料”标题，不使用外边框或四格统计。整块区域使用随主题适配的柔和底色（bg-soft）、8px 圆角和 16px 内边距，与列表区分。简介使用 14px、1.7 倍行高并完整展示。简介下间隔 20px，以左右排列的信息行依次展示创建时间、累计行动数和最近行动时间。创建时间使用图的创建日期，显示年月日，悬浮显示完整时间；最近行动时间沿用列表的自然日期格式，没有行动时显示“暂无”，不使用图资料修改时间代替。底部展示最多 5 位参与者的 28px 头像，间距 4px，按节点作者首次出现顺序去重，悬浮显示昵称、点击进入主页，不表示贡献排名。超过 5 人时在末尾显示同高度的“+N”，表示未展示的人数，悬浮显示完整人数说明；不超过 5 人时不显示。参与数和表达数只在图名片显示。

图设置底部提供“删除图”。创建者或参与者（参与名单包含本人，或本人在图内发布过行动）可以看到删除入口，未参与者不提供入口。创建者、参与名单及本图节点作者去重后达到 2 人时，禁止删除；删除按钮保留并禁用，悬浮或键盘聚焦时提示“已有其他用户参与，不能删除此图”。执行时再次检查参与情况，不能绕过禁用状态删除。普通参与者可进入设置查看删除限制，但不因此获得编辑图资料的权限。只有本人参与时，空图直接删除；有节点时确认框显示将删除的准确节点总数，包括行动、表达和形成过程。确认后同时校验参与情况与节点数量，状态变化则拒绝删除并要求重新确认。删除同步清除该图及其节点、旧版关联内容和反应状态，返回行动图列表并显示轻提示，其他图保持不变。

图名片背景铺满整张卡片，居中裁切，卡片最小高度 240px，不叠加全图黑色遮罩。底部横向铺设亚克力信息层，浅色主题使用 55% 不透明度的白色，深色主题使用 50% 不透明度的黑色，配合背景模糊和饱和度增强；标题、统计信息与头像边缘随主题适配。信息层左右内边距 24px、上下内边距 16px。信息集中在左下角，头像 48px、标题 18px、统计信息 12px。头像与文字间距 10px，标题与统计间距 4px。标题位于头像右侧，可自然换行；标题下显示参与数和表达数。参与数按节点作者去重，表达数与表达列表条目数一致。简介只在图资料中显示，放在统计数据上方，完整展示内容。保持页面既有顶部留白和左侧返回按钮的位置。

用户未设置头像时使用昵称首字，图未设置头像时使用标题首字，拉丁字母使用大写。图列表与图详情使用同一头像组件；无自定义背景时展示统一的蓝色几何线条网络背景图。个人资料和图设置保留图片上传，已设置头像可以恢复文字头像，图背景可以恢复默认。演示站的上传图片随当前页面会话生效。

固定导航为 **表达 / 约定 / 行动 / 探索 / 搜索 / 设置**，默认进入表达。内容为空时仍显示对应栏目；设置按现有图编辑权限显示。各栏目各自占用下方内容区域，不使用悬浮设置或折叠按钮。

约定列表沿用三行纯文本摘要，下方提取被满足的那份约定 Markdown 内的图片，最多显示三张正方形缩略图，超过三张在第三张右下角显示“+N”；无图不占位。继承时使用实际约定版本中的图片，不借用来源行动、本次行动或本节点向后的新约定附图。点击缩略图使用共享单图预览，不切换探索、不提供前后切图；其他正文保持定位对应箭头。完整约定继续按 Markdown 顺序展示图片，详情大图允许切换。

约定栏目展示已明确满足来源约定的跨用户引用，每条对应一条真实箭头，不展示自我引用、满足自己原始约定的引用、无约定、未核对或不满足的关系。同一行动满足多个直接来源约定时分别展示，不合并不同回应。按回应行动发布时间倒序排列，沿用列表与右侧图资料布局、无限滚动和 tab 状态保留。条目依次显示双方头像昵称及“满足了……的约定”、最多三行的约定正文、对应行动标题、自然时间与节点编号。继承约定归属于实际设置版本的作者，补充“经由某人的节点 #N · 约定来源 #M”。头像昵称进入各自主页；时间、节点编号不跳转；正文、约定和行动标题统一进入探索，定位并选中该引用箭头，右侧展示引用双方、来源约定和核对结果。定位以箭头的几何中心为目标，清除之前无关的链路高亮。返回约定栏目恢复列表条数和滚动位置；没有记录时显示“暂无满足约定的跨用户引用”。

搜索栏目只搜索当前图，右侧保留图资料。先用二级 tab 选择“表达 / 约定 / 行动 / 用户”，下方显示对应的独立搜索表单。表达搜索路线终点标题及当前有效表达（含继承），行动搜索节点标题及行动记录，两者均可按作者筛选；表达作者按列表中的路线终点作者匹配。约定搜索已满足的跨用户引用，匹配有效来源约定正文或回应行动标题，可分别按满足者、约定提出者筛选；继承的约定按实际约定版本作者归属，不把中间传递者当作提出者。用户只匹配实际发布过行动的去重用户昵称，不匹配邮箱或简介。作者和双方筛选使用可搜索昵称的选择控件，允许不填关键词、仅按人搜索。文档按标题精确匹配、标题部分匹配、正文匹配依次排序，同级按发布时间倒序；约定按回应行动时间倒序，用户昵称精确匹配优先。

回车或点击搜索才提交当前分类的条件，修改输入或筛选不立即替换已有结果。输入框的清除按钮只清空草稿关键词；重置只清空当前分类的条件与结果。四个分类分别保留草稿、已提交条件、结果、页码和滚动位置，切换其他分类、进入探索或往返用户主页都不清空。搜索结果统一分页，每页最多六条，不使用无限滚动。

文档搜索结果复用现有简略信息，摘要仍最多三行，截取命中位置附近的原文并突出关键词；点击正文进入探索、定位节点并打开相应文档。约定结果复用约定回应卡片，点击正文定位并选中对应箭头。头像和昵称进入各自主页，缩略图打开单图预览，不触发探索跳转。用户结果显示头像、昵称、简介和本图行动数，整个条目只跳转用户主页；返回行动图后恢复搜索。示例验证条件：表达“十八分钟”、行动“番茄”（含分页）、约定“用时”或满足者“乔”加提出者“林岚”、用户“Robin”。

- **表达**：每条路线当前终点的有效表达，一条路线一项。展示终点标题、作者头像与姓名、时间、层级和最多三行的表达摘要。沿用的表达另外标明实际来源节点与作者。空表达保留为空状态，不拿事实摘要替代。
- **行动**：所有节点实际记录的行动，按发布时间从新到旧排列。使用第 6 节的简略信息规范，摘要最多三行；点击标题、摘要进入探索，点击附图查看大图。
- **探索**：保留固定宽度的 Cytoscape 节点图与右侧文档/引用详情工作区。
- **设置**：编辑图标题、简介、头像和背景图。图片通过上传选择，不填 URL；保存后留在设置栏目。

表达与行动列表及搜索结果不显示节点图，使用相同的整项点击交互。头像与用户名进入作者公开主页；日期与层级为普通信息，点击不跳转；附图打开大图，可切换全部图片；标题、摘要与其他空白区域点击进入详情，不另设“在探索中查看”按钮。进入详情时切换到探索、定位并选中该节点：从表达进入打开表达，从行动进入打开行动。该节点的完整引用历史作为当前路线背景；浏览其他节点不改变这次进入的路线。“定位当前路线”返回本次路线终点，不假定存在全图统一的最佳主线。

列表常显“第7层”等层级信息，不再常显节点编号。层级统一按全图引用关系计算，含合入来源，不能根据列表排序或节点编号推算。节点图圆点仍只显示层级；节点悬浮信息和详情显示“节点 #14 · 第7层”。引用通过稳定编号定位，编号不随层级或排序变化。

列表时间按浏览者本地日期依次显示“今天 HH:mm”“昨天 HH:mm”“周几 HH:mm”（本周其他日期，周一至周日）、“M月D日 HH:mm”（本年）或“YYYY年M月D日 HH:mm”（往年）。昨天优先于跨周、跨年判断；悬浮显示完整日期时间。

列表右侧的“图资料”在简介下显示参与人、支链、事实和最近更新：参与人按节点作者去重；支链按当前路线终点计算，包含只有起始节点的路线；事实按全部节点计数；最近更新取最新行动节点时间，没有节点时回退到图元信息时间。沿同一路线继续时，表达项移到新终点；分叉增加独立路线；被后续合入的终点不再单独作为当前终点。

## 2. 节点图

### 2.1 节点代表一次行动记录

每个节点只代表用户真实发生的一次行动记录。行动可以是尝试、复做、调整、失败、部分结果或新的观察，只要用户愿意记录，就可以成为节点。系统不要求行动对应某个目标，也不判断行动是否“完成”。

用户可以先行动，再与 AI 对话，把行动经过、结果和观察整理成一份记录，最后决定是否发布为节点。AI 对话是记录的形成过程，节点是公开可阅读的行动结果。

节点编号使用行动图内稳定的 `节点 #N`：按节点创建顺序分配，节点进入主线或支链后都不重新编号，也不会因为主线排序变化而改变。主线/支链是节点的关系属性，编号是节点本身的身份。

圆点里的数字表示层级，不是节点编号。起始节点为第 1 层，后续节点为所有直接引用来源中最深层级加 1。同一层可以有多个节点；多来源引用不累加各条路线的节点数量。悬浮信息同时显示层级和稳定编号，编号继续用于唯一定位。

### 2.2 固定宽度的纯节点图

左侧采用 Cytoscape + Dagre 的纵向图，图宽固定为 340px。节点圆点只显示层级数字，标题、稳定编号、作者、摘要和约定在悬浮时显示，不保留旁边逐行对齐的标题列表。

引用来源位于后续行动下方，较新的行动在上方；不同分支可以共享高度，不要求一个节点占一整行。图增加时向下延伸，不将全部历史缩进可视区域。

```text
      7         7
     / ×      /  ╲
    6        6     3
      ╲     /      │
         5        2
```

图形含义分别定义，不互相替代：

- 圆点代表一次行动；箭头由来源行动指向后续引用它的行动。
- 实线表示来源作者与新节点作者相同；虚线表示不同作者之间的引用，与当前浏览者身份无关。
- 不满足来源约定时，在线上显示叉号。符合约定时不增加标记；缺少核对结果时不能假装符合，悬浮时说明。
- 叉号只表示不满足来源约定；同作者和跨作者引用均无需申请或等待同意，连线详情保留不符合原因。
- 主线使用绿色，其他路线使用较弱的颜色。选中状态用外圈强调，点击支链不会改变主线。
- 承接与合入都保留真实连接，二者在连线悬浮信息中说明，不再通过实线与虚线区分。
- 选中时强调当前节点及全部引用来源历史；其他路线降低对比度但不消失，点击不重新布局。

当前不实现精华、热门或竞争评分。首次直接进入探索时使用最新路线终点；从列表进入时使用所选节点作为路线终点。绿色只强调沿主要承接关系追溯的路径；合入历史使用蓝灰色填充节点和连接线，保留完整背景但不混成一条主线。选中节点外圈独立于路线强调，其他分支降低对比度但保持可见。浏览节点、连线不改变路线终点。该强调只辅助阅读，不评价哪条路线更有价值。

#### 背景外观

节点图背景属于个人全局外观设置，在“设置 → 外观 → 行动节点图”调整，与显示图例开关放在一起。提供纯色、点阵、细线网格、十字网格；纯色不显示纹理参数。点阵可调直径 1～3px，网格线宽 0.5～1.5px，十字大小 4～8px、线宽 0.5～1.5px；各纹理可调间距 16～40px 和深浅（浅、标准、明显）。默认点阵、直径 2px、间距 24px、浅色纹理。预览与实际画布使用同一纹理组件，颜色随主题变化。调整自动应用并保存在浏览器，不修改行动图数据；各背景分别保留参数，支持恢复默认。

### 2.3 长支链的折叠

长链不能把所有支链节点一次性铺开。折叠时保留分叉起点、最近节点、当前选中节点和必要的汇合点，中间使用一行关系提示：

```text
● 节点 #20
│
⋮ 支链 A 中间还有 18 个行动
│
● 节点 #39
```

折叠提示本身属于图轨道的一部分，点击后展开这一段节点。支链数量、最近行动时间和参与者可以作为提示信息显示，但不能把支链改写成待完成的方案。

进入探索图时默认选中当前主链终点。用户点击某个支链节点后，历史图保留其他路线，强调选中节点及其来源上下文，并在当前节点附近展开必要的历史。

当前 frontend 使用 Cytoscape + Dagre，显示行动图已提供的行动数据。长支链折叠和分批加载尚未实现，不能靠压缩横向位置长期容纳无限分支。番茄炒蛋的 #13、#14 演示多来源引用，#10 → #13 演示同作者引用不符合约定，#3 → #6 演示跨作者引用不符合约定，两者都只标记 ×。

### 2.4 悬浮信息

悬浮或键盘聚焦节点时显示：

- 节点层级、稳定编号与行动标题。
- 作者头像、用户名、时间。
- 最多三行的客观行动摘要，以及可选的一张缩略图。

悬浮或键盘聚焦连线时只显示双方节点编号、层级、作者、承接或合入关系和核对结果。点击后在右侧查看来源约定和不符合原因。悬浮信息不替代右侧完整文档。

### 2.5 节点操作

- 点击节点：右侧切换到该节点。
- 点击连线：持续高亮该引用，右侧显示引用双方、完整来源约定、核对结果与不符合原因。点击双方节点卡片可返回对应文档，也支持 Enter 或空格选择连线。
- 点击支链节点：保留图中其他轨道，右侧显示该行动记录。
- 点击顶部“定位当前路线”：选中本次路线终点并滚动到可见位置，即使已经选中也可以再次定位。
- 点击“接续行动”：以当前节点为上下文，开始记录下一次行动；从已有分叉的旧节点接续自然形成另一支链。
- 已有行动的行动图不在页头提供无上级的记录入口，用户需从具体节点继续记录。
- 按节点编号定位、长支链折叠作为后续功能。

### 2.6 引用背景与本次实现边界

新节点的已知历史执行事实仅来自直接引用节点以及沿全部引用关系追溯到起始节点的历史。多来源取并集并去重，不包含同一行动图里未引用的其他分支，也不能用“编号减一”计算历史数量。历史观点仍然是观点，不能当作已验证事实；本次行动另由用户提供新增事实。

不符合约定不会阻止引用，也不会扩展历史事实范围。想纳入另一条路线的执行事实，需要增加引用。

本次实现节点图、悬浮信息、引用关系详情和样例数据中的约定状态展示。编写新行动时支持设置后续约定，并将来源的有效约定用于 AI 对话整理；发布校验和完整的 AI 事实背景约束仍属于后续功能。没有核对结果时保留未知，不能推断为满足或不满足。

## 3. 右侧节点详情

选中节点时，右侧展示其两份行动记录之一。它不使用“摘要 / 详情”切换，因为摘要和详情不是两个业务状态；默认展示客观行动记录，需要理解这次行动如何形成观点时再切换到行动表达，需要追溯时进入形成过程。选中连线时，此处切换为引用关系详情。

界面入口简化为“行动”和“表达”两个 14px 普通文字按钮，不使用带底色、边框或阴影的分段控件。当前项以主题绿色显示，另一项为灰色；按钮只切换当前节点的文档。切换栏在右侧内部滚动时吸顶，标题和作者区正常滚出。

### 3.1 节点头部

```text
节点 #14  第7层 │ 承接 #11  合入 #7
整理出自己的番茄炒蛋原则
头像 jo · 周三 19:40
```

头部说明稳定节点编号、层级、路线位置、行动记录标题、作者、时间和后续关系。不额外生成一个需要别人总结的标题。

表达、行动列表维持 28px 头像、14px 用户名。探索节点详情和悬浮卡使用 32px 头像、14px 用户名，日期与层级保持 12px 灰色辅助信息，时间复用列表的相对日期格式，悬浮查看完整时间。作者头像和昵称可进入公开主页，返回探索后保留选择和阅读位置。节点标题 20px，可换行；正文 15px、行高 1.85，左右留白 24px。

直接来源放在顶部节点编号、层级之后，以细竖线分组。承接节点只有一个，显示可点击的“承接 #11”；只有一个合入来源时显示“合入 #7”，多个时统一显示“合入 N 个节点”。点击数量展开来源列表，包含节点编号、标题和作者，限制列表高度并允许内部滚动；点击条目关闭列表并查看该节点。不在头部展开祖先节点或完整历史。

### 3.2 默认内容

其他用户默认看到行动记录：

```text
头像  用户名  时间

这次把番茄先炒到出汁，再加入蛋液。两次复做都控制在 20 分钟内，第二次减少了调味步骤，出锅后更接近想要的酸甜味。

图片缩略图

留下的观察：火候变化比调味先后更影响口感。

接续行动   查看形成过程
```

公开内容默认由行动经过、实际结果和行动者留下的观察组成。节点可以没有图片，也可以包含多张图片；图片只在实际存在时显示。右侧提供两份记录的切换：客观行动记录只描述本次发生的事实，行动表达基于本次行动和历史上下文形成观点、判断与偏好。

完整文档中的图片按 Markdown 的位置穿插显示，每张独占一行，保留原始比例，不裁切；旧数据中未嵌入正文的附件在文末按原顺序单列补齐，已嵌入的图片不重复追加。点击图片打开大图，可切换当前文档的全部图片；列表摘要仍使用独立的缩略图布局。

“查看形成过程”进入独立资料页，按“节点身份信息 → 引用背景与表达处理状态 → 约定文档 → 连续 AI 对话 → 文档结果”排列。页内顶部依次是返回入口与图名、行动标题、作者与日期；稳定编号及层级放在作者行右侧，不重复页面标题。背景和表达状态共用柔和底色的信息区，采用一致的 13px 字号、行高和固定标签列宽；背景默认收起，表达的后续编辑信息另起次要行，避免挤在状态旁。约定文档保留在 AI 对话前，默认折叠，各区间距统一为 24px。作者头像、昵称、自然日期、稳定编号及层级与探索详情一致。行动和表达始终由同一条连续对话整理，可以一起讨论事实和观点，不要求先完成行动对话再开始表达对话。修改表达基于已有的全部对话继续，形成过程按顺序展示一次完整聊天，不按文档拆分或重复对话。下方文档结果提供“行动 / 表达”切换，切换后直接展示全文，不再使用折叠层或重复文档标题。继承表达保留实际来源入口，不把上游的聊天混入本节点的对话。表达为空时仍可查看空结果，以追溯未填写或清空的选择；不改变探索详情隐藏空表达按钮的规则。

引用背景默认收起，摘要区分承接与合入，只显示直接来源及历史数量；展开后分别查看来源约定、核对状态、不符合原因、历史节点和记录时保存的 AI 指引。来源编号可进入对应节点的形成过程。当前图关系只能说明引用背景，不等同于 AI 实际请求输入，相关说明放入问号帮助，不伪造生成快照。

表达处理状态区分首次填写、修改自、继承自、主动清空及未填写；继承来源指向实际文档，不把继承内容当作当前对话的生成物。后续通过“补充表达”保存的内容记录补充者及时间，新消息接在原始对话之后；没有保存的补充对话不推断。探索无表达时仍隐藏表达按钮，形成过程的状态信息不影响这一规则。厨艺示例对话中的发布选择必须与节点的更新、继承和清空状态一致。

### 3.3 一个节点中的内容

一个节点对应一条行动记录，不再把多条行动强行合并，也不再把一次行动拆成两种内容。记录可以包括：

- 行动标题或首句。
- 行动者、时间和可选地点等基本信息。
- 实际做了什么，以及过程中的关键变化。
- 行动产生的结果、失败或部分结果。
- 行动者留下的观察、判断或下一步想法。
- 图片等行动证据。
- 用于形成记录的 AI 对话和 Markdown 历史。

如果用户连续做了两次行动，应发布为两个节点；后一个节点通过接续关系连接前一个节点。这样每个节点都保持清楚的时间和行动边界，也让主线和支链能够反映真实的行动路线。

### 3.4 表达的更新、继承与清空

事实只记录本次行动。表达允许没有新内容，并按以下规则解析：

1. 当前节点明确更新表达：采用新内容。
2. 当前节点未更新：沿主要承接关系继承上一节点的有效表达；继续向前查找最近一次更新或清空。
3. 当前节点主动清空：有效表达为空，停止向更早节点查找。后续节点未更新时也继承这个空值。
4. 起始节点没有表达：保持为空。
5. 合入节点提供事实背景，但不自动覆盖或拼接主要承接关系上的表达。

数据上区分“未更新”和“主动清空”：缺省表达字段代表继承，空字符串代表主动清空，非空字符串代表更新。不能用真假值回退到历史表达或事实文档。

表达列表、探索右侧、形成过程页使用同一套规则，清空不删除历史表达。有表达时，正文上方显示“修改自 节点 #11”或“继承自 节点 #11”，来源指向实际提供上游表达的节点，跳过仅继承的中间节点。首次写入且没有非空上游表达时，不显示来源。探索详情中的来源编号可点击，切换到来源节点的表达，链路高亮不变。

节点有效表达为空时，隐藏“行动”右边的“表达”按钮，始终展示行动正文，不显示空表达占位。未被其他节点承接或合入的链路终点，在“接续行动”右边显示入口：有效表达为空时叫“补充表达”，已有有效表达（包括继承内容）时叫“修改表达”。两个入口复用与接续行动相同的单栏工作区，提供“AI 对话 / 行动 / 表达 / 约定”四个 tab，不在节点详情下方直接编辑 Markdown。默认显示已有连续对话并定位到末尾，继续输入新消息；表达 tab 预览 AI 整理的完整表达。行动 tab 展示当前节点的行动原文与图片，约定 tab 展示当前有效约定及其各直接来源约定，均为只读，不提供约定编辑器。头部身份条显示“节点 #编号”、当前标题和不含当前节点的上游历史；接续行动则显示“承接 #编号”和包含承接节点的引用历史。两种流程共用消息样式、真实参与者头像、输入区、完整 Markdown、各 tab 阅读位置和固定底部操作栏；接续行动底部为“发布行动”，表达编辑底部为“保存表达”。请求带入当前节点的事实、全部已引用历史事实、当前有效表达、来源约定和行动图指引，不含未引用分支。初始内容只读且不能直接保存；必须完成新一轮对话生成后再确认。清空也在对话中提出，AI 返回空表达后点击保存才生效。

记录新行动时，工作区采用单栏满宽布局，提供“AI 对话 / 行动 / 表达 / 约定”四个 tab，默认进入 AI 对话。AI 每轮同时维护行动文档与表达的继承 / 更新 / 清空选择；行动和表达 tab 均只读，表达不再使用手写文本框或独立选择器，在聊天中说明修改意图。约定 tab 直接展示本节点约定的设置，来源约定保留在下方按需展开。无上级时表达默认空；有上级且未要求更新时默认继承，已有表达草稿随连续对话带入后续请求。格式不完整的 AI 返回不能覆盖草稿，最新一轮失败不能发布旧生成结果。

接续页头部显示承接节点编号、标题与引用历史数量，提供“合入节点”入口，按当前图的节点编号、标题搜索，预览行动全文及有效约定，可选多个其他分支的终端节点。终端节点指当前图内没有被后续节点承接或合入的节点，与是否填写表达无关。承接节点及其已知历史不重复列入候选；不同图的节点不能合入。发布前重新检查终端资格；已选来源若被接续或合入，标记“已非终端”，阻止生成和发布，允许逐项移除后重新选择、继续 AI 对话。该限制作用于新合入，不改写历史引用关系。选中来源显示“合入 #编号”、约定核对状态和移除按钮，头部最多显示三个，其余通过“另 N 个合入”进入选择器查看。历史由承接及全部合入来源的上游行动取并集，去除重复祖先，不包含未引用分支。表达和后续约定仍默认沿承接关系继承，合入来源不会自动拼接。约定 tab 下方按直接来源分别展示承接/合入、编号、标题、有效约定版本、核对结果及说明；无约定标为“无约定”，缺少核对结果标为“尚未核对”，不推断为满足。不满足仍允许发布，对应连线标 ×。

增删合入来源保留输入和已有文档草稿，但清除上一轮核对结果、将草稿标为待重新整理，必须完成新一轮 AI 对话才能发布；生成期间禁止修改来源。AI 按本轮来源重新整理，移除来源不再作为已知历史事实。发布保存全部合入节点 ID、每个直接来源的核对结果、去重后的历史数量及直接来源快照，详情与连线复用这些真实关系。每个 tab 保留草稿、文档、约定选择和各自的滚动位置，只有 AI 对话 tab 显示输入区；新回复到达时对话定位到末尾，不主动切换 tab。发布操作固定在整个工作区底部，各 tab 共用同一份待发布内容。预览复用详情页的完整 Markdown 渲染，行动和表达切换后直接展示正文，不再使用逐行文本渲染，也不重复文档标题。表达显示实际继承版本的节点编号；空表达保持为空，不显示虚假的继承文案。生成时约定编辑暂时禁用，避免同一轮输入前后不一致；请求失败保留输入供重试，失败消息和欢迎语不写入发布对话。

发布后继续对话只更新当前节点的表达和新增的对话记录，保留原始对话，不新增行动，不改来源、行动事实、约定或关系。原始聊天与新增聊天在界面上连接为同一条对话，进入时定位到对话末尾，形成过程也只展示一次完整对话并记录参与者。返回原节点时未保存的内容不生效，保留探索选择与阅读位置。仍为终点时可以继续通过对话更新；出现后续承接或合入后隐藏入口，提交时重新检查资格。AI 请求失败时保留文档草稿和输入，撤回失败的临时用户轮次以避免重试重复，错误提示不写入已保存对话；不能将旧生成结果冒充本轮结果保存。

发布行动默认沿用，可选择更新或清空；AI 提取的观察不自动视为用户同意更新表达。

行动图可设置可选的 AI 对话指引。指引只约束提问和整理方向，不能改写事实。查看表达时仅显示紧凑的历史数量与表达来源，不铺开全部上下文节点；完整直接来源、历史范围和 AI 对话在形成过程页查看。

### 3.5 节点约定与来源约定

约定与表达共用继承机制：缺省字段沿承接关系逐级继承，非空字符串设置新版本，空字符串主动清空并阻断更早版本。合入来源不会自动覆盖或拼接后续约定。来源追溯至实际设置版本的节点，跳过未修改的中间节点；修改只从当前节点向后生效，不改写历史。

正文和操作按钮下方依次显示“约定”“来源约定 N · 待核对 M”，均默认收起，不放在头部，不新增文档 tab。前者展示后续引用采用的有效约定及“继承自 / 修改自 节点 #N”，空状态显示“无约定”，已清空时可追溯清空节点。后者汇总所有直接承接、合入来源的有效约定，按来源去重，不额外叠加已被替代的祖先版本；无有效约定的来源不计数，一份约定的多个条款仍算一份。

待核对只统计尚未记录核对结果的来源。不满足约定的引用无需申请或等待同意，不计入待核对。展开后按来源显示承接/合入、来源编号、作者、核对结果和不符合原因，约定全文另行展开；直接来源编号与约定版本编号均可切换到对应节点。连线详情及形成过程也使用同一有效约定。满足、尚未核对、不满足分别呈现；不满足只在连线上标记 ×，不阻止引用。修改或清空本节点的后续约定不会取消本次引用的来源要求。

编写行动时，“约定”默认折叠并沿用上个节点，可展开修改或清空；首个节点默认不设置。没有可继承的内容时显示“无约定”，操作为设置约定，不提供多余的清空选项。修改预填继承内容，空白修改不能发布，需要明确选择清空。发布仅保存当前选择，不修改来源；AI 对话收到的来源要求与本节点向后传递的约定分开，缺少事实时询问或保留未知，不能为满足约定编造事实。AI 每轮同时返回直接来源约定的核对结果：满足、不满足及原因、尚未核对。仅接受真实直接来源编号，不允许重复或额外来源；缺失结果保留未知，不推断为满足。不满足与尚未核对均不阻止发布；发布保存已核对的结果及原因，连线、详情和形成过程据此统一展示，不新增申请审批流程。

发布后，没有后续承接或合入的节点可编辑约定，条件与表达一致：有效约定为空时叫“补充约定”，已有内容（包括继承内容）时叫“修改约定”。入口仍放在“约定”栏右侧，与展开按钮分开，不加入主操作行。点击在栏内预填当前有效内容，可取消；已有内容提供独立的“清空约定”按钮，只清空草稿，点击“保存约定”后才生效，取消则保留原约定。手动删为空白不能直接保存为清空。保存前重新检查终点资格，保存为本节点版本，不改来源；展开约定全文并轻提示。不新增节点、不改行动、表达、来源核对或原始 AI 对话。表达、约定均记录最近一次编辑者、时间及补充/修改/清空类型，在形成过程中明确标记发布后的操作，不伪造编辑对话。

厨艺示例保留现有关系结构，#8 继承 #5、#9 修改继承的版本、#12 清空但仍保留对 #9 的满足记录；同时保留 #13 的同作者不符合约定、#14 的双来源、#5/#6/#15 的跨作者不符合约定和 #18 的未核对。演示对话同步记录约定选择与不符合原因。

## 4. 滚动与阅读

顶部介绍与其他页面保持一致的顶部留白。返回按钮放在详情卡左侧留白，上边缘与详情卡对齐，图标 18px、点击区域 32px。

- 表达与事实使用页面自然滚动，摘要均最多三行，不在列表内展开文档。
- 列表切换到探索再返回时，保留各列表的数据、顺序和各自的阅读位置，不重新创建列表。
- 直接切换探索栏目时保留当前选择与内部阅读位置；从列表的定位按钮进入时，以本次选择为准。
- 栏目导航吸顶，高 44px；探索工作区占据其下剩余可视高度，左侧为可平移、缩放的画布，右侧详情独立滚动。定位后导航与工作区共同铺满窗口，随时可以点击表达或行动返回。
- 图顶部“重新铺满”仅显示图标，将工作区重新对齐窗口顶部，不进入浏览器全屏，不改变所选节点。
- 画布操作和右侧滚动不带动外层页面。按节点与文档类型分别保存右侧阅读位置，连线详情也独立保存；首次选择回到顶部，重新查看恢复原位置。从列表或搜索明确定位时打开正文顶部。节点和连线互斥选中；返回探索保留画布的平移位置与缩放比例。
- 选中连线沿原路径加粗，保留颜色、实虚线与叉号，不使用矩形选框。

## 5. 用户阅读路径

### 探索中的临时链路高亮

- 选中节点与高亮链路相互独立。直接进入探索默认不高亮；从表达、行动或搜索结果进入时，选中目标并自动高亮以其为终点的主要承接路径，合入历史作为背景区分。
- 图顶部显示紧凑的“链路 #编号”状态，悬浮查看终点标题，并提供定位终点与取消高亮的图标按钮。
- 取消只移除链路与背景强调，不改变所选节点、右侧文档、阅读位置或图布局。状态区恢复显示节点数量，保持图可视区域高度稳定。
- 浏览其他节点、点击引用关系不替换高亮链路；节点详情顶部的“高亮链路”按钮可以主动更换或重新开启高亮。
- 定位终点只滚动图，不更换所选节点或右侧文档；没有链路高亮时，图工具栏提供定位选中节点。
- 切换栏目保留上述状态，不重新选取所谓全图主线。

### 只看图与定位阅读节点

- 右侧节点详情提供“定位此节点”和“隐藏详情”图标按钮；引用详情也可隐藏。
- 隐藏详情后，节点关系区域占满工作区。详情展开、隐藏或窗口尺寸变化时，画布适配新的宽度，让当前节点保持可见；选择引用时以目标节点定位。靠近图边缘时限制平移，避免为了居中末端节点而留下大面积空白。保留节点拓扑关系与链路高亮，不重新生成布局。
- 再次点击节点或连线会打开对应详情。点击原节点恢复原文档类型与阅读位置，点击其他节点正常切换内容。
- 普通切换栏目后仍保持隐藏；从表达、行动或搜索结果明确进入探索时主动显示详情。
- 右侧定位把当前文档节点移到画布中央；左侧链路定位仍对应高亮终点。两者均保留缩放比例，不修改文档、阅读位置或链路高亮。
- 拖动画布空白区域平移，滚轮或触控板缩放；工具栏提供缩小、放大、比例和适应画布，缩放范围为 35%～250%。适应画布展示全图；重新铺满仍负责将工作区对齐窗口，两者职责独立。画布获得焦点时可使用方向键平移、加减键缩放、0 适应画布。

打开行动图 → 阅读不同支链的表达 → 切换事实看实际行动 → 点击摘要查看完整文档或点击“在探索中查看”追溯具体路线 → 选择节点或引用关系 → 查看形成过程或从该节点接续。

表达无需每次更新，允许整条路线当前没有表达。事实列表仍然正常展示这些节点；历史表达可通过探索回看。

## 6. 帖子简略信息规范

本节保留此前反复调整的帖子简略信息规范，目前应用于“事实”列表。表达与事实列表均使用最多三行的摘要，完整文档在探索右侧阅读。

### 6.1 简略卡内容

```text
节点编号
行动记录标题
头像 用户名 · 时间
行动摘要
图片缩略图
```

### 6.2 显示限制

- 标题最多 1 行，超出省略。
- 作者信息 1 行，头像与用户名同时显示。
- 行动摘要最多 3 行，超出省略。
- 图片最多显示 3 张缩略图。
- 没有图片时不保留图片区域。
- 默认显示行动摘要，不显示目标字段或状态提示。
- 简略卡不展示 AI 对话正文，只提供进入记录形成页的入口。

### 6.3 简略卡的使用原则

简略卡保持紧凑、信息层级清楚，不重复生成楼层标题。点击标题、摘要进入探索并打开对应文档，附图独立查看大图。点击表达或行动 Tab 返回时恢复原列表位置。

## 7. 默认界面与按需帮助

按熟练用户使用设计默认界面：直接展示内容、状态和操作，不常驻功能教程与机制解释。

- “节点关系”标题旁的问号收纳层级数字、连线、叉号、主线和浏览操作的详细解释。全局“设置 → 界面偏好”控制图例显示，默认隐藏；图例只列实线、虚线、叉号和节点内数字的含义，并记住本机浏览器中的选择。图设置只负责图形象和基本信息，不替代全局界面偏好。
- “行动 / 表达”旁的问号解释两份文档的区别、AI 整理方式及形成过程入口。
- 引用详情标题旁的问号解释作者关系、约定标记和历史背景范围；正文只保留实际引用双方、约定、核对结果、不符合原因和背景数量。
- 形成过程页去掉重复的功能副标题，将说明集中在页头问号内。
- 问号点击后展开轻量帮助浮层，支持关闭按钮、点击外部或 Escape 关闭，并恢复键盘焦点。不在悬浮时自动弹出说明。
- 行动图简介、作者文档和来源约定属于实际内容；错误、尚未核对等状态属于操作依据，均不能作为说明文案隐藏。行动图指引不常驻页头，但可在相关记录的形成过程中查看。

## 8. 当前设计结论

以表达、事实两种内容流作为日常阅读入口，以探索图追溯行动关系。事实对应单个节点，表达对应每条路线终点的有效表达；表达可更新、继承或主动清空。设置保持独立同级栏目。当前实现保留原节点图交互及约定展示，不引入热门评分、精华筛选或新的主线竞争算法。
